Getting Started with Monica

Learn how to create a new .NET project and configure Monica as your infrastructure foundation.

Monica is a highly modular, performance-oriented framework for building modern .NET applications. It heavily relies on the concept of modules to keep your codebase decoupled and organized.

Prerequisites

  • .NET 8.0 SDK or later installed.
  • Basic understanding of Dependency Injection in ASP.NET Core.

Installation

The easiest way to get started is by installing the core package via NuGet:

dotnet add package Monica.Core

Note: `Monica.Core` provides the fundamental module system and basic abstractions. You will typically install additional modules (like `Monica.UI` or `Monica.EventBus`) depending on your application's needs.

Initializing the Framework

In your `Program.cs`, you need to register Monica and define your root module. Monica uses a builder pattern to configure its options and register dependent modules.

using Microsoft.AspNetCore.Builder;
using Microsoft.Extensions.DependencyInjection;
using Monica.Core;

var builder = WebApplication.CreateBuilder(args);

// Add Monica and register the root application module
builder.Services.AddMonica(mo =>
{
    mo.AddModule<AppModule>();
});

var app = builder.Build();

// Initialize the module system before starting the app
await app.UseMonicaAsync();

app.Run();

Defining a Module

Every feature in Monica is a module. A module is simply a class that implements IModule, but it's easier to inherit from MoModule.

using Monica.Core.Modularity;
using Microsoft.Extensions.DependencyInjection;

// The [DependsOn] attribute defines the module loading order
[DependsOn(typeof(MonicaCoreModule))]
public class AppModule : MoModule
{
    public override void ConfigureServices(ServiceConfigurationContext context)
    {
        // Register your specific services here
        var services = context.Services;
        // services.AddScoped<IMyService, MyService>();
    }
}

Warning: Ensure you do not create circular dependencies between your modules. The module loader will throw an exception during startup if a cycle is detected.
