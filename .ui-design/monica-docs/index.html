Program.cs
var builder = WebApplication.CreateBuilder(args);

// 1. Add Monica Core
builder.Services.AddMonica(mo =>
{
    mo.AddModule<RAGModule>()
      .AddModule<EventBusModule>();
});

var app = builder.Build();

// 2. Initialize Infrastructure
await app.UseMonicaAsync();

app.Run();

Why choose Monica?

Designed for enterprise-grade applications, focusing on clean architecture, high cohesion, and low coupling.

True Modularity

Every feature is a module. Use what you need, leave what you don't. Completely independent without requiring the entire framework.

Domain-Driven Design

Built-in support for rich models, ensuring behavior stays on the object that owns the data. High cohesion out of the box.

Res Pattern

Unified result model for public Facades. Cleanly separate infrastructure entry points from internal exception-throwing services.
