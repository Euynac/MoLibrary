# Examples.Monica

This small compile-checked project contains focused source examples that do not need their own runnable host.

## Project Structure

- `DataChannel/` — pipeline middleware and display-metadata examples for `Monica.DataChannel`.
- `Repository/` — entity-configuration examples for `Monica.Repository`.
- `MoDecoratorExample.cs` — decorator behavior from `Monica.Experimental`.

## Getting Started

Build `Examples.Monica.csproj` with the repository solution. For complete runnable hosts, use `examples/JobSchedulerMinimal` or `examples/Monica.ReferenceApplication`.
