# Local drafting templates

## Issue or documentation defect

```markdown
## Summary

## Affected Monica version and immutable source

## Minimal reproduction

## Expected behavior

## Actual behavior

## Evidence and diagnostics

## Duplicate search

## Proposed scope
```

## Design discussion

```markdown
## Problem and users affected

## Constraints and non-goals

## Alternatives considered

## Proposed contract

## Breaking changes and migration

## Documentation and testing impact
```

## Pull request plan

List the approved Issue/Discussion, intended branch scope, implementation boundaries, tests, bilingual documentation changes, release notes, and validation commands. Keep the plan local until the current session explicitly authorizes branch or remote creation.

Never place credentials, private filesystem paths, personal data, proprietary source excerpts, or vulnerability details in a public draft.
